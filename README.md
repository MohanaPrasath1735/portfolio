# Mohana Prasath J | Portfolio

A responsive 4-page personal portfolio built for the NeuroTech assignment.

**Live site:** https://mohanaprasath1735.github.io/portfolio/

## Pages
- Home
- About
- Projects
- Contact

## Built with
- HTML5 (semantic tags)
- CSS3 (Flexbox, Grid, media queries, CSS variables)
- JavaScript (mobile menu)
- GitHub Pages (hosting)

## Features
- Fully responsive (desktop and mobile)
- Mobile hamburger menu
- Custom colour theme using CSS variables

## Run locally
1. Clone the repo
2. Open the folder in VS Code
3. Start with Live Server
